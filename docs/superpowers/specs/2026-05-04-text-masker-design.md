# 文字掩盖器 (Text Masker) 设计规格

## 概述

一款用于背书的文字掩盖工具。用户粘贴文字后可调节掩盖百分比，点击 Mask 按钮随机掩盖指定比例的文字。点击掩盖处可短暂显示原文，帮助记忆。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  [粘贴/输入区域]                              [−] [□]  │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    掩盖结果显示区域                      │
│              (高亮色块遮盖文字，可点击揭示)              │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  百分比: [25%] [50%] [75%] [100%]         [🔀 Mask]    │
└─────────────────────────────────────────────────────────┘
```

## 组件规格

### 1. 输入区域 (InputArea)

- **功能**: 粘贴待掩盖的文字
- **样式**: 折叠前显示 `<textarea>`，折叠后隐藏
- **折叠按钮**: 右上角，折叠后显示一个小输入框图标
- **行为**: 用户粘贴后不会自动折叠，需手动折叠（保持用户控制）

### 2. 掩盖结果显示区域 (MaskedTextDisplay)

- **功能**: 展示被掩盖的文字内容
- **掩盖效果**: 纯色块遮盖（深灰色 `#333333` 背景，白色文字）
- **揭示行为**: 点击遮盖块 → 显示原文 → 2秒后自动恢复掩盖
- **显示模式**: 按句子或段落分割，每段为可交互单元

### 3. 控制栏 (ControlBar)

- **百分比选择器**: 分段按钮组 [25%] [50%] [75%] [100%]
- **当前选中**: 高亮样式（如边框或背景色）
- **Mask 按钮**: 触发随机掩盖逻辑
- **布局**: 左侧百分比按钮，右侧 Mask 按钮

## 交互逻辑

### Mask 操作流程

1. 用户粘贴文字到输入区域
2. 选择掩盖百分比（如 50%）
3. 点击 Mask 按钮
4. 系统随机选择指定比例的文字片段进行掩盖
5. 结果显示在下方区域

### 掩盖算法

- 将文本按句子或固定长度分割为多个片段
- 根据百分比随机选择要掩盖的片段
- 每次点击 Mask 按钮会重新随机选择（可产生不同结果）

### 揭示行为

- 点击掩盖块 → 短暂显示原文（2秒）→ 自动恢复掩盖
- 揭示时使用不同背景色（如浅蓝色）表示"已揭示"

## 技术选型

- **React 18** + **Vite** — 快速启动
- **纯 CSS** — 无需额外样式库
- **Zustand** — 状态管理（简化）
- **单页应用** — 无需路由

## 验收标准

- [ ] 输入区域可正常粘贴和编辑文字
- [ ] 输入区域可折叠/展开
- [ ] 四个百分比按钮可切换，当前值有视觉反馈
- [ ] 点击 Mask 按钮后，指定百分比的文字被随机掩盖
- [ ] 每次点击 Mask 产生不同的随机掩盖结果
- [ ] 点击掩盖块可显示原文，2秒后自动恢复
- [ ] 页面美观，掩盖效果清晰可见
- [ ] 移动端可正常使用
